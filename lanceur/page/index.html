Ouvrir vos PDF et vos images dans PDFEdit Or, en un double-clic

Un petit programme gratuit pour Windows, à installer une seule fois.

Ce que fait ce module

Sous Windows, quand vous double-cliquez sur un PDF ou une image, le fichier s’ouvre directement dans PDFEdit Or, dans votre navigateur. Plus besoin de le glisser à la main dans la page.

Si PDFEdit Or est déjà ouvert, le nouveau fichier s’ajoute dans un nouvel onglet de l’éditeur, dans la même page : votre travail en cours n’est pas touché et le navigateur n’ouvre pas d’onglet en plus.

Votre fichier ne quitte pas votre ordinateur : le lanceur le transmet de votre disque à votre navigateur par une connexion interne à votre PC, et uniquement au site PDFEdit Or. Il n’envoie rien à Ardoisia.

Ce qu’il faut

  • Windows 10 ou 11 (pas de version Mac pour le moment).
  • Google Chrome ou Microsoft Edge (récents).
  • Votre compte Ardoisia, connecté dans ce navigateur.
  • Aucun droit administrateur : l’installation ne concerne que votre session Windows.

Télécharger

Télécharger le lanceur (.zip)

Petit fichier (moins de 100 Ko). Il contient l’installeur et le code source du lanceur, lisible par tous.

Installation (5 minutes, une seule fois)

  1. Téléchargez le fichier .zip ci-dessus, puis faites un clic droit dessus et choisissez « Extraire tout… ».
  2. Dans le dossier obtenu, double-cliquez sur « Installer-lanceur.cmd ». Une fenêtre noire s’ouvre, prépare le lanceur puis affiche « Installation terminée ».
  3. Windows ouvre ses réglages. Faites un clic droit sur un PDF, puis « Ouvrir avec », « Choisir une autre application », « PDFEdit Or (web) », cochez « Toujours utiliser cette application » et validez. Windows impose de faire ce choix vous-même.
  4. Refaites la même chose avec une image (.jpg, .png…) si vous voulez aussi les ouvrir ainsi.
  5. Double-cliquez sur un PDF : PDFEdit Or s’ouvre avec votre fichier. La première fois, Chrome ou Edge peut demander d’autoriser l’accès au réseau local pour ce site : acceptez, c’est seulement votre propre ordinateur.
Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires » puis « Exécuter quand même » : le fichier n’est pas signé par un éditeur payant, mais son code est lisible dans le dossier.

Au quotidien

  • Vous pouvez sélectionner plusieurs fichiers : ils s’ouvrent chacun dans leur onglet.
  • Une image est importée comme avec « Importer image → PDF » : reconnaissance du texte, puis PDF d’une page.
  • Si le fichier s’ouvre dans un onglet du navigateur qui n’est pas affiché, cliquez sur l’onglet PDFEdit Or : un site web ne peut pas se mettre tout seul au premier plan.
  • Le lanceur travaille en arrière-plan, sans fenêtre, et s’arrête seul quelques minutes après la fermeture de PDFEdit Or.

Désinstaller

Double-cliquez sur « Desinstaller-lanceur.cmd » dans le même dossier : le programme et ses réglages Windows sont retirés, et Windows reprend son programme habituel pour les PDF.

Un problème ?

  • Rien ne s’ouvre : vérifiez que « PDFEdit Or (web) » est bien l’application par défaut des PDF (étape 3), puis réessayez.
  • Le navigateur affiche la connexion Ardoisia : connectez-vous, puis double-cliquez de nouveau sur le fichier.
  • Le fichier est refusé : le lanceur ne prend que les PDF et les images (jpg, png, webp, bmp, gif), jusqu’à 250 Mo.
  • Pour utiliser un autre navigateur que celui par défaut, ouvrez le fichier « lanceur.ini » du dossier d’installation et indiquez-y son chemin.
